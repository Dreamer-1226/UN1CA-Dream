ViPER4Android 2.1.1 for dm3q / One UI 9

Audio Tweaks order:
  Play boot sound effect
  PortROM audio by Lindir Music
  ViPER4Android (master processing switch)
  ViPER effects and profiles (opens the app)

The APK owns the master preference, device profiles and presets. Settings calls
a provider protected by WRITE_SECURE_SETTINGS and a caller-package check. The
app and QS tile continue to use the same DataStore preference. Disabling the
master releases effects and preserves profiles. No reboot is needed to toggle.
Default processing is OFF; global mode defaults ON. Per-app mode is available
with MODIFY_AUDIO_ROUTING. Boot autostart remains controlled by the app.

The non-AIDL driver is extracted from the pinned upstream release ZIP. Native
installation adds registrations to existing effect XML files after paradigm and
PortROM. It preserves all existing Samsung effects, offload configuration,
Audio Eraser, speaker protection and audio policy. No root-manager scripts,
live mounts, permissive SELinux or audio-service restart hooks are installed.
prepare.py rejects an unexpected HAL and verifies pinned payload checksums.

The source archive plus patch-app.py and UnicaControlProvider.kt reproduce the
modified app. It uses the ROM AOSP test certificate, not platform identity.
Upstream APK updates use a different signing identity and cannot update this
ROM variant. Update the ROM payload through build-app.sh instead.
